## 🧠 О чём проект

Это не просто набор тренировочных планов.  
Это **полноценный портал**, который ведёт тебя через 3 адские тренировки в неделю.

Одна главная страница — хаб. Три дочерние — сами тренировки.  
Никакой воды. Только железо, пот и дисциплина.

---

## 💀 Доступные тренировки

| День | Тренировка | Время | Фокус | Акцент |
|------|------------|-------|-------|--------|
| **ПН** | Бицепс + Трицепс + Запястья | 75–80 мин | Руки — полный фарш | 🔴 красный |
| **СР** | Плечи + Трапеция | 50–60 мин | Дельты, ширина, рельеф | 🟣 фиолетовый |
| **ПТ** | Грудь + Спина | 60–80 мин | Жимы + тяги, мощный торс | 🔵 синий |

## ⚙️ Технологии

- **HTML5** — семантическая разметка (`<main>`, `<article>`, `<header>`, `<footer>`)
- **CSS3** — кастомные свойства, градиенты, `cubic-bezier`, `interpolate-size`, медиа-запросы
- **JavaScript** — плавное появление блоков, таймеры отдыха, управление состоянием

---

## 🎨 Особенности дизайна

- 🔥 **Тёмная тема** с агрессивными акцентами: золотой, красный, фиолетовый, синий
- 🎯 **Единая палитра** — эталон на главной, каждая тренировка берёт свой главный цвет
- 💀 **Атмосфера "адского" стиля** — никакой скуки
- 📱 **Mobile-first** — от 320px до десктопа, без динозавров

---

## ✨ Анимации

- **Появление блоков** через `height: 0 → auto` + `opacity` + `translateY`
- **Единый тайминг**: `cubic-bezier(.22, .61, .36, 1)`, длительность `.6s`
- **Хореография** — JS вешает класс `.is-shown`, CSS анимирует; никаких inline-стилей
- **Смена шрифта** заголовка (`Patrick Hand` → `Rubik Dirt`) после shrink-анимации
- **Кликабельные таймеры отдыха** с состояниями `is-running` / `is-done` и звуковым сигналом
- **`prefers-reduced-motion`** — уважаем пользовательские настройки
